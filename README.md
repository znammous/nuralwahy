# نور الوحي — nuralwahy.app

صفحة تطبيق «نور الوحي» لحفظ القرآن ومراجعته. التطبيق نفسه في [znammous/quran-kids](https://github.com/znammous/quran-kids).

- النصوص: العربيّة في `index.html`، وبقيّة اللغات في `i18n.js` بمفاتيح `data-t`.
- اللقطات: `img/<لغة>/` من `scripts/store/capture.cjs` في مستودع التطبيق.
